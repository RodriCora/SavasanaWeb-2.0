# SavasanaWeb
Savasana Web
Proyecto web desarrollado para la gestión de productos y registro de usuarios.

🚀 Descripción
Savasana es una plataforma e-commerce sencilla que permite a los usuarios:

Registrarse e iniciar sesión.

Visualizar un catálogo de productos.

Gestionar un carrito de compras.

🛠️ Tecnologías utilizadas
HTML5: Estructura semántica.

CSS3: Estilos, animaciones y diseño responsivo.

JavaScript: Lógica de autenticación, carrito y manipulación del DOM.
